# Python Learning Journey

A collection of beginner Python exercises and small command-line projects — the starting point of my programming journey. Each script practices a core concept: input handling, control flow, functions, and error handling with `try/except`.

## 📂 Projects

| File | Description |
|---|---|
| `calculator.py` | A basic calculator supporting +, -, *, / with input validation and division-by-zero handling |
| `area_calculator.py` | Calculates the area of a circle, rectangle, or triangle based on user choice |
| `hypotenuse_calculator.py` | Calculates the hypotenuse of a right triangle using the Pythagorean theorem |
| `temp_converter.py` | Converts temperatures between Celsius, Fahrenheit, and Kelvin |
| `weight_converter.py` | Converts weights between kilograms, grams, and pounds |
| `compound_interest_calculator.py` | Calculates compound interest given principal, rate, compounding frequency, and time |
| `number_guessing_game.py` | The computer picks a random number 1-100 and the player tries to guess it, with "too high/too low" hints |
| `madlibs.py` | A Mad Libs-style word game that builds a short story from user-provided words |
| `atm_simulator.py` | Simulates basic ATM operations: check balance, deposit, withdraw, with balance/overdraft validation |
| `shopping_cart.py` | Lets the user add items with price and quantity, then prints an itemized receipt with a total |

## 🚀 Getting Started

Only Python's standard library is used — no external packages required.

Run any project with:
```bash
python <filename>.py
```

For example:
```bash
python number_guessing_game.py
```

## 📚 About

This repository documents the first stage of my Python learning path: writing small, self-contained programs that read user input, validate it, and handle errors gracefully instead of crashing. The journey continues in other repositories covering PyTorch models and networking projects.
